ITECC04 DSA Defense

1. Min-Heap Priority Restock Queue

Why Min-Heap over Array Sorting?
When a shipment arrives or an order is fulfilled, stock changes dynamically. A Min-Heap allows inserting or extracting the lowest-stock item in O(log n) time and inspecting the critical bottleneck in O(1) time without having to re-sort the entire warehouse inventory.

Key Defense Line: "We chose a binary Min-Heap to guarantee that the agricultural co-op immediately knows which critical crop input is nearing stockout without scanning all inventory items."

2. Merge Sort Revenue Ledger

Why Merge Sort over QuickSort or BubbleSort?
Merge Sort guarantees O(n log n) time complexity in the best, average, and worst cases (no O(n²) worst case like QuickSort on already-sorted receipts). Furthermore, Merge Sort is a stable sort, preserving original transaction order for identical revenue values.

Key Defense Line: "Merge Sort's divide-and-conquer paradigm guarantees consistent reporting speed and stability for auditing fiscal records."

3. Binary Search SKU Lookup

Why Binary Search over Linear Scan?
Warehouse barcodes and SKUs are standardized. With 10,000 agricultural SKUs, a linear scan requires up to 10,000 comparisons, whereas Binary Search cuts the search space in half at each iteration, requiring at most 14 comparisons (log₂ 10,000 ≈ 13.3).

Key Defense Line: "By maintaining products ordered by SKU, cashier scanning operates at logarithmic speed O(log n)."

4. FIFO Warehouse Dispatch Queue

Why an Explicit Queue?
Prevents concurrency hazards where two cashiers sell the last bag of Urea Fertilizer simultaneously. Orders are staged in order of arrival; warehouse dispatch deducts stock sequentially. If an order needs editing, dequeuing from the queue head maintains strict FIFO discipline.

Key Defense Line: "The FIFO Queue decouples order placement from inventory deduction, preventing race conditions during peak planting seasons."

Frequently Asked Defense Questions (Universidad de Dagupan Panel)

Q1: Why did you implement custom DSA classes instead of using Python's built-in sorted(), heapq, or SQL queries?

"Built-in methods hide internal mechanics. To fulfill the ITECC04 project requirements and demonstrate complete algorithmic understanding, we implemented pointer arithmetic, recursive splitting, and heap invariant maintenance directly in pure Python."

Q2: How does the category-based SKU generation work?

"Each category uses an agricultural prefix: FERT for fertilizers, SEED for seeds, FEED for feeds, and AGRO for agrochemicals. The system scans existing SKUs in the database for that prefix, finds the highest numeric sequence, and formats the next sequential SKU (e.g., FERT-006)."

Q3: How does the queue handle edits without breaking FIFO order?

"The cashier can dequeue the order currently at the head of the dispatch queue, which pulls it out in strict O(1) FIFO order back into the active ticket for corrections. This prevents arbitrary-index mutations while keeping inventory state clean."
